# @order-sync/shared

Cross-process code: the env schema (`.`), the database schema (`./db`), and
token encryption at rest (`./crypto`).

## Database

Schema lives in `src/db/schema.ts`. Migrations are generated by drizzle-kit
and checked in under `drizzle/`.

### Local setup

```sh
docker compose up -d                 # from the repo root
```

That starts Postgres with a `ordersync` database and a separate
`ordersync_test` for integration tests.

Put the connection strings in the repo-root `.env`:

```sh
DATABASE_URL=postgres://ordersync:ordersync@localhost:5433/ordersync
TEST_DATABASE_URL=postgres://ordersync:ordersync@localhost:5433/ordersync_test
```

### Commands

```sh
pnpm --filter @order-sync/shared db:generate   # schema change -> new SQL in drizzle/
pnpm --filter @order-sync/shared db:migrate    # apply pending migrations to DATABASE_URL
```

`db:generate` needs no database. `db:migrate` reads `DATABASE_URL` (falling
back to `TEST_DATABASE_URL`) and is safe to re-run — applied migrations are
recorded and skipped.

### Integration tests

The schema integration test skips itself unless `TEST_DATABASE_URL` is set:

```sh
docker compose up -d
TEST_DATABASE_URL=postgres://ordersync:ordersync@localhost:5433/ordersync_test pnpm test
```
